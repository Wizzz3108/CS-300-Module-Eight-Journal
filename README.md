# Course Planner BST

A C++ course planning application that uses a binary search tree to organize, search, and display academic course information efficiently.

## Overview

This project focused on solving the problem of helping academic advisors efficiently manage and access course information without manually sorting or searching through large amounts of data.

The application takes a raw course data file and organizes the information into a binary search tree, allowing courses to be stored in an ordered structure and retrieved efficiently. The project demonstrates how the way data is stored directly impacts program efficiency, scalability, and performance.

## Technologies

- C++
- Binary Search Trees
- Data Structures
- Object-Oriented Programming
- File Processing

## Highlights

- Implemented a binary search tree to organize course information
- Loaded course data from external files
- Created search functionality for retrieving individual courses
- Displayed courses in sorted order using tree traversal
- Managed course prerequisites and validated course relationships
- Applied structured programming practices to keep code organized and maintainable
